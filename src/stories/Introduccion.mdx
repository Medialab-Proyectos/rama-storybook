# Rama · Sistema de diseño

Implementación en Angular del sistema de diseño **Rama** de Figma (archivo *Rama (3)*), organizada con Atomic Design.

## Origen de los datos

- **Tokens** (colores, tipografía, espacios, radios, bordes, sombras, desenfoques y grillas): exportados de Figma con el plugin *Design Tokens*. Viven en `src/tokens/tokens.ts`; el comando `npm run tokens` genera `src/styles/tokens.css` con todas las variables `--rama-*`.
- **Temas**: el archivo de Figma tiene dos modos de color. **Rama** (azul, por defecto) es el que usan los componentes; **Ecopetrol** (verde) es el del export JSON. Difieren en la escala primaria y en los semánticos information, caution, warning y el borde default. Cámbialo con el selector "Tema" de la barra superior; en una app, con `data-theme="ecopetrol"` en `<html>`.
- **Íconos**: el sistema usa Iconsax. Los que usan los componentes se descargaron de Figma a `public/icons/`; los demás son un set provisional del wireframe REVO. Para agregar más, exporta los SVG de la página "1.3 Iconos" a `public/icons/` y corre `npm run icons`.
- **Componentes**: construidos a partir de las páginas de Figma (variantes, estados y valores exactos), comparados con capturas de cada una.
- **Menú y sidebar**: versión "[NEW]" de Figma (página 2 Menu / Sidebar navigator): sidebar con módulos e íconos, búsqueda rápida, submenú con ayudas, y topbar con "Entradas rapidas" en los tamaños 1728 / 1024 / 744 / 440. Las imágenes de ejemplo están en `public/nav/`.

## Organización: Atomic Design

El Storybook se ordena de lo más simple a lo más compuesto:

| Nivel | Qué contiene | Componentes |
|---|---|---|
| **Fundamentos** | Los tokens: las decisiones de diseño que no son componentes. | Colores, Tipografía, Íconos, Sombras y desenfoques, Espacios, grillas y bordes |
| **Átomos** | Las piezas mínimas de interfaz; no se pueden dividir sin perder su función. | Button, Badge, Tag, Badge vs Tag (guía de uso), Avatar, Checkbox y Radio, Input y Text area |
| **Moléculas** | Grupos pequeños de átomos que cumplen una sola tarea. | Button group, Breadcrumb, Tabs, Dropdown list, Search input, Autocomplete, Datepicker, Alert, Card, Uploader button |
| **Organismos** | Secciones completas de interfaz que combinan moléculas y átomos. | Menú y Sidebar, Table, Search table, Calendar, Modal y Pop up, Panel lateral, Uploader de documentos, Uploader card |
| **Plantillas** | Estructuras de pantalla con los organismos ubicados, sin contenido real. | Por construir (p. ej. Home de Figma) |
| **Páginas** | Plantillas con contenido real de un producto. | Por construir |

Cada historia indica en su componente la página de Figma de la que sale (archivo **Rama (3)**). El código vive en `src/lib/` y las historias en `src/stories/<nivel>/`.

## Cómo usar los tokens

```css
.mi-tarjeta {
  background: var(--rama-bg-default-white);
  border: var(--rama-border-width-thin) solid var(--rama-border-inset);
  border-radius: var(--rama-radius-large);
  padding: var(--rama-space-16);
  box-shadow: var(--rama-shadow-small);
  color: var(--rama-text-default-black);
}
```

Para los estados usa los tokens semánticos y no el hex de la paleta: `--rama-error-surface`, `--rama-text-error`, `--rama-border-error-emphasis`, etc.
